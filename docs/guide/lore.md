# World lore

Farm Tycoon begins with a common arrival hall and fields that do not arrive fully planted. Each farmer chooses a plot and places the first soil. The town grows from useful work: wheat buys the first barn, the barn shelters animals, the feedmill supports them, and each new workshop turns a harvest into something the next neighbor needs.

The depot keeps older equipment in use because this valley values practical knowledge. A shutter protects a route; a counter helps a worker; a furnished room gives a visitor somewhere to rest. The town is built one useful thing at a time.

This is original setting fiction. It is not a claim that unfinished quests, characters, or buildings are already playable. The live guide carries the complete current lore text, and this article preserves its canon and publication boundary.
